# SurvivalZtext
Esto es un prototipo de videojuego de supervivencia zombie creado en Python, para terminal, es completamente jugable pero no está terminado. (Aproximadamente al 25% de el proyecto final en mente)


Funciona en Windows, Linux y Termux

Requisitos:

python3

git

Instalacion en Linux y Termux:

descargar:

 git clone https://github.com/Valbef/SurvivalZtext.git


Abrir:

cd SurvivalZtext/SurvivalZtext

python3 main.py


-Actualizar:

cd SurvivalZtext/SurvivalZtext

git pull

---Instalacion en Windows:

1. Descarga solo el archivo EXE, ponlo dentro de una carpeta y haz doble click,

   en esa carpeta se creara la carpeta "partidas" donde se guardaran las partidas...

   para actualizarlo descargar el nuevo archivo EXE desde mi pagina de github y sustituir el anterior.

   No borrar la carpeta partidas si quieres mantener las partidas anteriores.



SEGUNDA OPCION PARA WINDOWS (RECOMENDADA)


Descarga Python desde la página oficial:

https://www.python.org/downloads/windows/

También puedes instalar el Python Install Manager desde Microsoft Store. 
Durante la instalación, asegúrate de que Python quede disponible desde la terminal.

Para comprobar que está instalado:

Pulsa Windows + R y Escribe:

  cmd

  Pulsa Enter.
  
  Escribe:

python --version

Deberías obtener algo parecido a:

Python 3.13.x

Desde mi pagina de GitHub descargar el juego en el boton verede "CODE" arriba a la derecha 
y descargar el ".ZIP".

descomprimir el archivo.

Abrir la carpeta del archivo y dar doble click en "main.py"
O click derecho en main.py, "abrir con" Python
